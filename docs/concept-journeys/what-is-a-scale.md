# What is a scale?

Treat SCALE first as an analytical operation: ordering pitch categories, often within
an octave.

Then ask what was removed:
- hierarchy
- trajectory
- phrase grammar
- register
- intonation variability
- instrument-specific tuning
- social or ritual function

Aka scale elicitation is a canonical stress test: a defensible analytical pitch model
need not correspond to a locally verbalized abstract object.
