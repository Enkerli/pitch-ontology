# Where is the centre?

Do not use ROOT as a universal property.

Compare:
- chord root
- tonic
- final
- drone/reference pitch
- reciting tone
- vādi / nyāsa
- karar / güçlü
- māye and return behavior

Possible relations include `PRIVILEGES`, `RETURNS_TO`, and `APPROACHES`; these allow
different kinds of centricity without declaring them equivalent.
