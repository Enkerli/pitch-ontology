# What is a note?

Start with the apparent primitive and progressively split it.

`frequency → pitch percept → pitch region/category → performed event → symbolic note`

These arrows are not identities and need not be one-to-one.

## Stress tests

- missing fundamental
- sung portamento
- gamaka
- saxophone multiphonic
- unpitched-to-pitched attack
- hazzāt as a map of remembered melodic motion
- MIDI Note On/Off as protocol events

## Ontology question

What perceptual, practical, representational, or institutional operation makes a
continuous or complex event count as *one note*?
